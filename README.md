Healthcare Data Analysis & Dashboard

Project Overview

An interactive healthcare analytics dashboard built using Python, Pandas, Plotly, and Streamlit.

Features

- Patient record KPIs
- Department and admission-type filters
- Admission date filtering
- Department-wise patient record analysis
- Billing and hospital-stay visualizations
- Patient outcome analysis
- Filtered data CSV download

Tech Stack

- Python
- Pandas
- NumPy
- Plotly
- Streamlit

Dataset

This project currently uses synthetic demo data created for learning and testing. It does not represent actual hospital records.

Run Locally

1. Install Python.
2. Install dependencies: "pip install -r requirements.txt"
3. Run: "streamlit run app.py"
